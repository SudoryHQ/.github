# Security Policy

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions or pull requests.

Email **contact@sudory.com** with:

- a description of the issue and its impact
- steps to reproduce or a proof of concept
- affected repository, version or URL

We will acknowledge your report within 3 business days and keep you informed until the issue is resolved.

## Scope

This policy applies to all repositories in the SudoryHQ organization and to services running on sudory.com.

## Disclosure

We ask that you give us reasonable time to fix the issue before any public disclosure. We are happy to credit researchers who report responsibly.
